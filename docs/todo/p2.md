## 换绑迁移（三场景）

> 交付：bot / 群组更换的三种迁移路径与迁移前广播，用户、topic、消息数据按场景保留或迁移。

- [ ] 场景一：bot 更换、群组不变——消息与 topic 保留，与新 bot 重新绑定；旧 bot 内人工广播引导
- [ ] 场景二：bot 不变、群组变更——用户无感知，topic 在新群组重建 / 迁移
- [ ] 场景三：bot 与群组都变——完整数据迁移策略
- [ ] 广播能力：换绑前向全部用户发送「客服已迁移，请添加新 Bot @xxx」
